# FitLog

## Project Name

**FitLog – Workout Tracking Website**

## Description

FitLog is a responsive workout tracking website designed to help users discover workouts, view detailed workout information, and manage their daily workout plans.

Users can browse available workouts, check workout details, add workouts to their daily plan, and save workouts for later. The application also provides a summary of the user's daily workout time and estimated calories burned.

The website uses a dark-themed and responsive interface that works across mobile, tablet, and desktop devices.

## Features

- Browse a collection of workouts
- View detailed information about each workout
- Add workouts to a personal daily plan
- Remove workouts from the daily plan
- Save workouts for later
- Track total workout duration
- Track estimated calories burned
- Search and browse workout content
- Responsive design for mobile, tablet, and desktop
- Dark-themed user interface
- Loading and empty states
- Toast notifications for user actions
