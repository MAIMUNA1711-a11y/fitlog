# FitLog 💪

## Project Name
FitLog

## Description
FitLog is a workout tracking website. Users can see a list of workouts, check details of each workout, and add workouts to their daily plan. Users can also save workouts for later. The app shows how many minutes and calories the user will spend today. This app is dark themed and easy to use on phone, tablet, and computer.

## Technologies Used
- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- React Icons
## Features
1. **Workout Library** – Shows 12 workouts as cards. Each card has an image, name, equipment, and stats (duration, calories, rating).
2. **Sort Dropdown** – Users can sort the workout list by Duration, Calories, or Rating.
3. **Workout Details Page** – Shows full information about one workout, like instructions, specs, and category.
4. **My Plan Page** – Shows workouts added to "Today's Plan" and "Saved" list. Also shows total exercises, minutes, and calories.
5. **Add / Save / Mark as Done / Remove** – Users can add a workout to plan, save it for later, mark it done, or remove it. Each action shows a toast message.
6. **Custom 404 Page** – Shows a nice error page if the user visits a wrong link.
7. **Fully Responsive** – The website works well on mobile, tablet, and desktop screens.
